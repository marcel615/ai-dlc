# Analytics 리뷰

변경 범위에 해당하는 항목을 공통 개발 리뷰와 함께 확인한다.

- **입력 데이터** — 출처와 사용 범위, 필요한 경우 기준 시점과 버전 또는 스냅샷을 확인할 수 있는가? 결과에 영향을 주는 결측·중복·형식 변경의 처리 방식이 정의됐는가?
- **처리와 평가** — 변환·집계·분석 규칙과 가정을 완료 조건과 대조했는가? 시계열 분석이나 모델 평가에서는 결과를 산출할 시점에 알 수 없던 정보가 입력에 섞이는지 확인했는가?
- **결과와 계약** — 산출물의 형식과 지표 정의가 명확한가? 다른 구성 요소가 소비하는 인터페이스와 결과 의미가 관련 공식 계약과 일치하는가?
- **재현과 검증** — 필요한 실행 환경, 입력과 설정, 실행 명령이 기록됐는가? 기대값을 확인할 수 있는 입력으로 변경된 처리와 관련 경계 조건을 검증했는가?

분석 실험을 마무리할 때는 확인한 결과가 다음 판단에 주는 의미를 완료 보고와 작업 기록에 한두 문장으로 남긴다. 추가 검증이 필요한 해석은 후속 검토 사항으로 표시한다.

프로젝트에 특화된 검증 기준은 대상 저장소의 문서와 작업 완료 조건에 기록한다.
