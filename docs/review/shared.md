# 공통 개발 리뷰

- 프로젝트 등록·대상 Git 루트·fetch/push 원격 및 역할별 설정을 확인했는가?
- 작업과 설계·승인 범위, 공식 원본 URL·SHA, 미결 사항과 실제 diff가 일치하는가?
- 공식 계약과 운영 파일 수정 권한을 준수하고, 계약 변경이 필요하면 대안·영향·보류 범위를 기록했는가?
- 적절한 테스트·검증을 실제 실행하고 결과와 미검증 사항을 구분했는가?
- PR 대상 브랜치, 최종 head의 CI·필수 리뷰, 기록과 사용자 직접 머지 조건을 확인했는가?

역할별 기준은 `docs/review/backend.md` 또는 `docs/review/frontend.md`를 함께 적용한다.
