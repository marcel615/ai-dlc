# 공통 개발 리뷰

- 프로젝트 등록·대상 Git 루트·fetch/push 원격 및 적용되는 영역 설정을 확인했는가?
- 작업과 설계·승인 범위, 공식 원본 URL·SHA, 미결 사항과 실제 diff가 일치하는가?
- 공식 계약과 운영 파일 수정 권한을 준수하고, 계약 변경이 필요하면 대안·영향·승인을 기록하고 같은 Task PR에 반영했는가?
- 적절한 테스트·검증을 실제 실행하고 결과와 미검증 사항을 구분했는가?
- Main이 실제 diff를 자체 리뷰하고, 공통 개발 절차에서 정한 독립 리뷰 대상이면 별도 리뷰를 받았는가? 리뷰 방식과 확인 결과를 PR에 기록했는가?
- 실행 가능한 검증을 마치고 확인된 버그·테스트 실패·필수 지적을 해결했는가? 환경·외부 의존성으로 남은 미검증은 PR 본문에 이유·영향·위험·후속 검증 방법·선행 조건·머지 전 필수 여부를 기록했는가?
- 미검증이 남아도 가능한 commit·push·PR·리뷰를 마무리하고 PR 준비와 머지 준비를 구분했는가? 권한·공식 원본·계약·요구사항 문제를 검증 보류로 우회하지 않았는가?
- PR 대상 브랜치, 최종 head의 CI·필수 리뷰, 기록과 사용자 직접 머지 조건을 확인했는가?

전문 기준은 영향받는 영역에 따라 `docs/review/backend.md`, `docs/review/frontend.md`, `docs/review/analytics.md`에서 확인한다.
