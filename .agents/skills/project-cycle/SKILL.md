# 프로젝트 사이클

`<프로젝트> 사이클 시작`, `<프로젝트> 사이클 N회 시작`, `<프로젝트> 사이클 재개` 요청에 적용한다. 공통 루트의 [AGENTS.md](../../../AGENTS.md)와 [프로젝트 사이클 절차](../../../docs/workflows/project-cycle.md)를 읽고 프로젝트·권한·진행 상태를 확인한다. 회차 생략 시 1회이며 한 회차에 후보 하나를 처리한다.

사이클 절차에서 지정한 기존 Skill과 Jira·리뷰 문서를 단계별로 읽는다. 실제 결과를 재조회하고 상태를 기록한다. 일부 작업이 막히면 의존하지 않는 작업을 먼저 마치고 남은 작업과 재개 조건을 저장한다.
