# 작업 상세화

[공통 규칙](../../../AGENTS.md), [통합 조정](../../../docs/workflows/orchestrator.md), [Jira](../../../docs/providers/jira.md), [리뷰 기준](../../../docs/review/orchestrator.md)을 읽는다. 선행 정제 실행 여부와 관계없이 실제 지정 작업과 필요한 Epic·자식·의존 관계를 확인한다.

- 최신 공식 원본 URL·SHA를 확인해 목적·범위·완료 조건·경계 동작·역할·의존성을 대조한다. 계약 변경 후라면 PR의 실제 머지와 원본 diff를 확인한다.
- 결정이 필요하면 근거·대안·권장안을 제시하고 사용자 결정을 확인한다. 결정 출처, 확정 범위, 미결 사항을 구분한다.
- Jira 작업에 관련 범위와 조건을 반영하고 기존 키·관계·결정 이력을 보존한다. 필요한 Specs 작업과 실제 차단 관계를 확인하거나 Jira 절차에 따라 등록한다. 승인된 범위의 Confluence 기획 논의를 기존 페이지에 연결해 보존한다.
- 실행한 변경과 미결 사항·재개 조건을 보고한다. 공식 명세 수정은 계약 관리 절차를 따르고, 독립 실행에서 Ready 전환은 사용자에게 남긴다.
