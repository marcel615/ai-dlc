# 프로젝트 논의 기록

공통 루트의 `AGENTS.md`, `docs/workflows/orchestrator.md`, `docs/providers/jira.md`의 프로젝트 논의 기록 절차 및 `docs/review/orchestrator.md`를 읽는다. 사용자가 기록을 요청한 경우에만 독립 실행한다. 기록 권한은 해당 Confluence 페이지 작성으로 한정한다.

1. 등록된 프로젝트와 적용할 `ai-dlc.yaml`을 확인한다. 요청에서 정한 범위 내에서 현재 대화의 해당 프로젝트 논의만 요약한다.
2. 주제마다 검색에 도움이 되는 핵심 키워드를 소제목에 넣고, 본문은 주제당 3~5줄 정도로 작성한다. 주요 논의, 결정 사항, 추가 검토 사항을 담고 해당 내용이 없는 항목은 생략한다. 결정 사항에는 사용자가 확정한 내용만 넣는다. 제안과 미결 질문은 추가 검토 사항에 적는다.
3. Confluence 절차에 따라 사용자 시간대의 `YYYY-MM-DD` 페이지를 생성하거나 최신 페이지의 기존 이력을 보존하면서 새 내용을 덧붙인다. 결정이 바뀌면 새 항목에서 무엇이 바뀌었는지 명시한다.
4. 확인한 페이지 링크를 반환한다. 쓰기가 보류되면 기록 초안과 보류 사유를 반환한다.
