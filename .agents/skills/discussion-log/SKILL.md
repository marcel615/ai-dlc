# 프로젝트 논의 기록

공통 루트의 `AGENTS.md`, `docs/workflows/orchestrator.md`, `docs/providers/jira.md`의 프로젝트 논의 기록 절차 및 `docs/review/orchestrator.md`를 읽는다. 사용자 요청으로 독립 실행할 때는 아래 대화 요약 절차를 따른다. 기록 권한은 해당 Confluence 페이지 작성으로 한정한다.

## 사용자 요청에 따른 대화 요약

1. 등록된 프로젝트와 적용할 `ai-dlc.yaml`을 확인한다. 요청에서 정한 범위 내에서 현재 대화의 해당 프로젝트 논의만 요약한다.
2. 주제마다 검색에 도움이 되는 핵심 키워드를 소제목에 넣고, 본문은 주제당 3~5줄 정도로 작성한다. 주요 논의, 결정 사항, 추가 검토 사항을 담고 해당 내용이 없는 항목은 생략한다. 결정 사항에는 사용자가 확정한 내용만 넣는다. 제안과 미결 질문은 추가 검토 사항에 적는다.
3. Confluence 절차에 따라 사용자 시간대의 `YYYY-MM-DD` 페이지를 생성하거나 최신 페이지의 기존 이력을 보존하면서 새 내용을 덧붙인다. 결정이 바뀌면 새 항목에서 무엇이 바뀌었는지 명시한다.
4. 해당 논의의 작업 후보와 진행 상태는 공통 Confluence 기록 절차에 따라 `작업 후보와 진행 상태` 페이지에 기록한다.
5. 확인한 페이지 링크를 반환한다. 쓰기가 보류되면 기록 초안과 보류 사유를 반환한다.

## 개발 마무리에서 절차 재사용

[공통 개발 절차](../../../docs/workflows/development.md#개발-중-발견한-개선점-기록)에서 선별한 항목이 있을 때 같은 프로젝트의 루트 설정에 있는 논의 기록 경로를 확인하고 [공통 Confluence 기록 절차](../../../docs/providers/jira.md#프로젝트-논의-기록)를 사용한다. 선별한 항목은 사용자가 확정한 결정과 구분해 추가 검토 사항으로 기록한다. 결과는 개발 마무리에서 보고한다.
