# 백로그 정제

[공통 규칙](../../../AGENTS.md), [통합 조정](../../../docs/workflows/orchestrator.md), [Jira](../../../docs/providers/jira.md), [리뷰 기준](../../../docs/review/orchestrator.md)을 읽는다.

1. 지정 후보를 우선하고, 자동 선정에서는 실제 승인 이력·필수 선행 조건·중복·우선순위를 확인해 최대 2개를 고른다. 명시적 사이클은 해당 회차 후보 하나만 처리한다.
2. 원본 목표와 승인·결정 이력을 보존한다. 설정된 공식 원본의 URL·SHA를 확인하고 범위·수용 조건·의존성·영역을 대조한다. 독립 추적할 구현 작업이 하나면 기존 후보 키를 유지한다. 기능 전체 완료를 별도로 판단해야 하면 Jira 절차에 따라 동일 키의 Epic과 필요한 작업만 사용한다.
3. 기존 작업과 Link Key·실제 관계를 대조해 재사용하고, 필요한 Specs Task와 차단 범위·해제 조건을 확인한다. 부분 성공이나 결과가 불명확하면 재조회부터 한다. Confluence 기획 기록이 필요한 경우 설정된 페이지와 상호 링크를 확인한다.
4. 변경 내용과 남은 조건을 보고한다. Ready 전환과 개발은 해당 작업 또는 사이클의 권한을 따른다.
