# 백로그 정제

[공통 규칙](../../../AGENTS.md), [통합 조정](../../../docs/workflows/orchestrator.md), [Jira](../../../docs/providers/jira.md), [리뷰 기준](../../../docs/review/orchestrator.md)을 읽는다.

1. 지정 후보를 우선하고, 자동 선정에서는 실제 승인 이력·필수 선행 조건·중복·우선순위를 확인해 최대 2개를 고른다. 명시적 사이클은 해당 회차 후보 하나만 처리한다.
2. 원본 목표와 승인·결정 이력을 보존한다. 공식 원본 URL·SHA와 관련 코드·테스트를 확인해 기능 범위·완료 조건·의존성을 정리한다. 같은 완료 조건의 변경은 후보 키를 유지해 하나의 Task로 관리한다. 독립된 완료 조건을 가진 여러 작업의 상위 완료를 추적할 때만 Jira 절차에 따라 같은 키의 Epic을 사용한다.
3. 기존 작업과 실제 관계를 대조해 재사용한다. 명세 변경이 필요하면 같은 Task에 변경 방향과 미결 결정을 기록한다. 부분 성공이나 결과가 불명확하면 재조회부터 한다. Confluence 기획 기록이 필요한 경우 설정된 페이지와 상호 링크를 확인한다.
4. 변경 내용과 남은 조건을 보고한다. Ready 전환과 개발은 해당 작업 또는 사이클의 권한을 따른다.
